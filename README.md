# EV3 Block Lab

小学校の授業で、Chromebook・WindowsのブラウザからLEGO MINDSTORMS EV3をプログラミングするための試作アプリです。バージョンは **0.23.3** です。

ブロックからEV3標準形式の実行ファイル（.rbf）を生成し、本体へ転送・読み戻し照合します。本体に保存したプログラムは、PCから切り離して本体で選択・実行できます。

v0.17.1では「＋ 新しいプログラム」を画面上部の「保存」「開く」の横へ移しました。マニュアルv0.17.0の「その他 → 新しい作品」は、このボタンに読み替えてください。

v0.18.0では、複数のスタートによる並行実行、条件・値の変化で始まるイベント、メッセージ送受信と完了待ちを追加しました。走行中も別の処理でセンサを読み、CSVへ記録できます。新機能の実機確認は継続中です。

[並行処理・イベント・メッセージの追加マニュアル v0.18.0](docs/manual-v0.18.0/README.md)

v0.19.0では、左右別速度の角度・時間指定、ブレーキ／惰性／保持、パワー指定、実測速度、回転数指定、動作中の速度変更を追加しました。

## GitHub Pagesで公開する

公開予定URL: https://davinichi.github.io/ev3-block-lab/

1. `davinichi/ev3-block-lab` をPublicで作成します。
2. このフォルダの内容をリポジトリの直下へ登録します。`.github/workflows/pages.yml` も必要です。ZIP自体をアップロードするだけでは公開されません。
3. リポジトリの **Settings → Pages → Build and deployment → Source** で **GitHub Actions** を選びます。
4. **Actions → Deploy EV3 Block Lab to GitHub Pages → Run workflow** を実行します。
5. Actionsの完了後、Pagesに表示されるURLを開きます。

当面はバックアップとして利用するため、mainブランチの更新時とプルリクエストではテストのみ実行します。GitHub Pagesへの公開は、正式公開時にPagesを設定してRun workflowを手動実行した場合だけ行います。手動でトークンをソースへ書く必要はありません。

公式手順: https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site

## 既存サイトから作品を移す

公開先が変わると、ブラウザの自動保存データは自動では引き継がれません。

1. 旧サイトで各作品を「保存」して `.ev3lab` をダウンロードします。
2. 新しいサイトの「開く」で読み込みます。
3. 共通のマイブロックは `.ev3blocks` に書き出してから、新サイトで読み込みます。
4. Bluetooth・USB機器は新しいサイトで接続先を選び直します。

旧サイト: https://ev3-block-lab-prototype.davinichi-9576.chatgpt.site/

自動保存は同じブラウザ内の現在の作品を保存する機能です。クラウド保存ではありません。学校の設定などで閲覧データが消去される場合に備え、授業の区切りで作品ファイルも保存してください。

## 主な機能

- 複数スタートによる走行・計測の並行実行（EV3本体で動作）
- 条件成立・値変化イベント、メッセージ送信・受信・完了待ち
- L/Mモーターの速度・角度・回転数・時間制御、ポート別停止、2台の同期制御
- 左右別速度の有限走行、停止方法の選択、パワー指定、実測速度、動作中の速度変更
- タイヤ直径・トレッドを使った距離移動、スピンターン、ピボットターン
- 左右の速度を−100～100%で個別指定して回し続ける制御
- 台形・S字の加減速（試作。S字は滑らかな速度変化を作る方式）
- 照合後すぐに起動する「転送して実行」とプログラム停止
- 接続中の入力1〜4とモーターA〜Dの値の表示・自動更新（現在のセンサーモードを保持）
- 秒単位のタイマー（小数対応）と共有タイマーのリセット
- 超音波・カラー・タッチ・赤外線センサー、モーターのエンコーダ取得・リセット
- 変数・引数・四則演算を常に小数で計算（EV3単精度、有効数字約7桁）
- EV3本体ボタンは当面、新規の一覧から非表示（保存済み作品の読み込みには対応）
- 本体の3色ランプ（緑・赤・オレンジ）の点灯・点滅・ゆっくり点滅
- ステアリング値による連続・角度・時間指定の曲線走行
- EV3単体でCSVログを記録し、再接続後にPC／Chromebookへ取り出し
- 余り・整数乱数・四捨五入・最小／最大・範囲内への制限
- UTF-8文字列、文字列変数、数値リストと合計・平均・最小／最大
- 比較、論理、条件分岐、繰り返し、引数付きマイブロック
- 全モーターを停止してプログラム全体を終了するブロック、呼び出し元へ戻るマイブロック終了ブロック
- 同名の引数レポーターは一覧に1個表示し、各マイブロックの呼び出し値は独立
- 作品とマイブロックの保存・読み込み、Bluetooth/USB転送・照合、転送完了音

左上にはプロジェクト名（EV3の保存先フォルダ）とプログラム名を入力します。保存時のファイル名は「プログラム名.ev3lab」です。

作品は `.ev3lab`、マイブロックは `.ev3blocks`、EV3実行用は `.rbf` です。作品・マイブロックは本アプリ専用形式で、LEGO純正ソフトの `.ev3` 形式とは互換性がありません。

## 接続と確認状況

BluetoothはWeb Serial、USBはWebHIDを使います。対応APIを利用できるChrome/Edgeなどで開き、学校の端末では機器接続の許可設定も確認してください。EV3の標準ファームウェアを対象としています。

Windows実機ではBluetooth転送、照合、本体保存、再起動後の単独実行、基本的な音・モーター動作が確認されています。Chromebookでの実機接続、USB接続、追加機能全体の実機検証は継続が必要です。公開先変更後の接続も実機で確認してください。

## 手元で起動・テストする

Node.js 24を使います。外部パッケージのインストールは不要です。

```sh
npm test
npm start
```

ブラウザで http://127.0.0.1:8765/ を開きます。

自動テストはコンパイル、命令構造、転送処理、模擬モーターなどを確認します。実機試験の代わりにはなりません。外部のEV3参照ファイルがない環境では、対応する参照比較テスト1件をスキップします。

## フォルダ

- `dist/`: 公開するアプリ本体。ビルド処理なしで配信できます。
- `tests/`: 自動テスト
