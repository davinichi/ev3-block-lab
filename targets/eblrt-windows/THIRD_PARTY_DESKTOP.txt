Unofficial educational evaluation software, 2026-11-04.

Cygwin binaries are NOT included in this ZIP. On first run the application downloads
unmodified upstream packages to its own directory. No administrator privileges,
global PATH changes, host Cygwin installation or system registry registration are used.
The pinned index is tool-setup/setup.ini; exact versions, URLs, sizes and SHA-512
are in tool-setup/manifest.json. The official setup verifies the signed package index.
Sources for those packages are identified by the source: entries in setup.ini:
https://mirrors.kernel.org/sourceware/cygwin/
https://cygwin.com/licensing.html
Notices are installed with each package in runtime/cygwin/usr/share/doc/.
