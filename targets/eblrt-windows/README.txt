EBL-RT Windows 0.3.6 / 2026-11-24
Web版 0.34.3-ev3rt.1 と編集画面を共通化しました。
・マイブロックを赤、通常の変数をオレンジに統一。
・定義の見出しを右クリックして編集。左一覧の個別編集ボタンは廃止。
・呼出しの「引数」見出しを省略。引数名・順序・値は維持。
・マイブロック一覧を文字コード順（英数字はASCII順）に整列。
・本体ランプを「画面」グループに統合。EV3の画像表示は維持。
・日本語・英語の共通操作追補をマニュアルへ追加。
既存作品、引数、最大8個の名前付き戻り値を維持します。
Windowsの完了音、コンパイル、USB・microSD・PAN転送の方式は変更しません。
コンパイラ・SDK・OSの更新はありません。

更新方法：作品を.ev3labで保存し、EBL-RTを終了してください。
更新用ZIPは旧EBL-RT.exeのあるフォルダーへ展開し、同名ファイルだけ上書きします。
resourcesフォルダーを削除せず、既存フォルダーへ内容をコピーしてください。
準備済みCygwinとuser-dataは更新ZIPに含めず、上書きしません。
一式ZIPは新しい半角英数字・空白なしのフォルダーへ全展開して起動します。
初回準備は従来どおりインターネット接続が必要です。
実機転送と走行、完了音の聞こえ方は今回未確認です。
