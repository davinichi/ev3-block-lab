# EV3-RT Cソース出力（試作）

EV3RT用の生成・転送は「EV3-RT · コンパイル・転送」で行います。標準EV3用の `.rbf` とは実行形式が異なります。「EV3-RT · コンパイル・転送」からモーターA〜DのL/Mを選び、「Cソース一式を保存（ZIP）」でソースを保存できます。本体への接続は不要です。

ZIPにはプログラム名のフォルダーが入り、`app.c`、`ebl_myblocks.c`、`ebl_myblocks.h`、`ebl_rt_runtime.c`、`ebl_rt_runtime.h`、`app.h`、`app.cfg`、`Makefile.inc`、手順の `README.txt`、中間データ `program-ir.json`、再編集用の `project.ev3lab` を収録します。

対象はTOPPERS/EV3RT **HRP3の動的アプリケーションSDK**です。HRP2は時間単位が異なるため対象外です。

## ビルドと実行

1. ZIP内のフォルダーを `hrp3/sdk/workspace/プログラム名/` へ配置します。
2. `app.c` の `ev3_motor_config` と `ev3_sensor_config` を配線と照合します。
3. EV3-RT開発環境で `hrp3/sdk/workspace` から `make app=プログラム名` を実行します。
4. 生成された `workspace/app` をmicroSDの `ev3rt/apps/プログラム名` へコピーします。
5. EV3-RTを起動し、Load App → SD cardから選択します。

実験室ではWindows補助アプリを経由してコンパイル・転送できます。ブラウザー単独でのコンパイルは行いません。詳しくは[実験手順](ev3rt-workbench.md)を参照してください。画面の通常の転送ボタンは標準ファームウェア専用です。音と基本モーターは利用者による実機動作報告があり、今回の追加機能は実機確認待ちです。

## 標準EV3との動作差

- 連続・時間指定の「速さ％」は `ev3_motor_set_power` に渡します。HRP3のL/Mモータードライバーは、このAPI名にかかわらず速度制御を使います。Lの未調整パワーにはUNREGULATED_MOTORを使用します。Mの種類を維持した未調整出力は公開APIで指定できないため拒否します。独立の有限動作は生成Cのエンコーダ制御、ネイティブ同期は `ev3_motor_steer` を使用します。標準EV3と同じ速度・停止特性になるかは実機確認が必要です。
- 停止はブレーキ／惰性／生成側の位置保持に対応します。保持は20ms周期・最大±20％の独自制御で、標準EV3と同じ停止特性を保証しません。
- モーターA〜DはダイアログでL/Mを指定します。モーターブロックのL/M表記から自動判定しません。停止のみ・エンコーダーのみ使うポートも構成します。
- 角度動作の監視は180秒で打ち切ります。回転量は開始時のエンコーダーからの相対値です。
- センサーは開始時に構成し500ms待ちます。同じポートに異なるセンサー種類を指定できません。実際のセンサーが使用可能になるまでの時間は実機で確認してください。
- ジャイロのリセットはソフトウェア基準点の更新です。
- ループ・待機・命令間で戻るボタンを確認し、停止します。正常終了時にも構成済みモーターを停止します。
- 数値はCのfloatです。数値関数の丸めや無効な測定値の扱いなどは標準EV3と完全一致する保証はありません。

## v0.28.0: 「動き」の全ブロック

左右モーター設定、タイヤ直径、トレッド、加減速（なし・台形・S字）、ステアリングの連続・角度・時間、左右別速度の連続・角度・時間、左右のスピン・ピボット、前進・後退の距離、左右ペアの停止を出力できます。

「動き」はEV3-RTの `ev3_motor_steer` でネイティブSTEP_SYNC制御を使います。有限角度は速い側（外側）のエンコーダーで監視し、完了後に両輪をブレーキ停止します。2個のモーター角度／回転数ブロックで「標準の同期」を選んだ場合も同期APIを使います。停止タイミング補正（feedback）は独立の有限動作として生成C側で制御します。

スピンの軸角度は「旋回角×トレッド÷タイヤ直径」、ピボットはその2倍です。直結タイヤを想定します。実際の旋回角には車輪の滑りや寸法誤差が影響するので、90度の精度は実機で調整してください。左右モーターの正転がそれぞれロボットの前進に合う構成が必要です。

加減速は動きの有限動作に適用し、連続走行と即時停止には適用しません。時間指定は実時間で速度を変え、角度指定の減速開始は測定したエンコーダー速度から推定します。標準EV3版と完全に同じ軌跡や加減速時間を保証するものではありません。左右別速度はネイティブ同期の整数ステアリング比へ丸めます。5秒間進行しない角度動作、または180秒を超えた動作は終了します。

検証: 全ポート順序・正逆・スピンとピボット各48条件、台形／S字、時間、左右別速度、停止・停止不能時の終了をCの模擬モーターで確認しました。実機への自動転送・実行は行っていません。

現行版では独立の有限動作にも加減速を適用します。連続回転は対象外です。開始時点の設定を使い、ネイティブ同期と独立制御はそれぞれの条件に従います。


## イベントとHRP3タスク（v0.30.0）

- 各スタート・イベント受信を `CRE_TSK` で定義し、監督用のメインタスクから `act_tsk` で起動します。合計16個の処理に加え、停止を管理するタスクを1個使用します。
- 条件は最初の成立、および偽から真への変化で実行します。値の変化は最初の値を基準に、それ以降の変化を検出します。
- 各イベントは処理終了後に20ms待って再監視します。処理中の同じイベントは重ねて起動せず、短い変化を取り逃がす場合があります。
- メッセージは世代番号で通知します。受信処理が忙しい間の複数通知はまとまり、1件ずつ蓄積するキューではありません。「送って待つ」は対応する全受信先の完了を待ちます。自己待ち・循環待ちは生成前に拒否します。
- イベント受信がある作品は、スタートの処理が終わっても動作を続けます。「プログラム終了」または本体の戻るボタンで全タスクを終了し、構成済みモーターと音を停止します。
- 数値変数は全タスクで共有し、読み書き・増分更新・複数戻り値の保存をセマフォで保護します。マイブロックの引数・一時値はタスクのスタック上で独立します。複数ブロックをまとめた処理全体の排他は保証しません。
- 駆動中の同じモーターへ別タスクが駆動命令を出すと、プログラム全体を停止します。明示的な停止命令は別タスクからも使え、途中の有限動作を打ち切ります。打ち切られたタスクは次の命令へ進みます。
- 動き・加減速の設定は共有です。有限の動きは開始時の加減速設定を保持します。単独・独立の有限動作も加減速に対応し、開始時の設定を保持します。センサーポートの競合は既存の検査で拒否します。
- PC上で生成Cをコンパイルして並行実行を検証し、ARM GCC 5.4とHRP3のSDKでELF生成を確認しました。実機でのタスク動作・応答時間の確認は未実施です。


## モーター拡張（v0.31.0）

- L/Mの単独・複数ポートの角度／回転数／時間指定に台形・S字の加減速を適用します。連続回転は対象外です。
- 独立の有限動作はポートごとのエンコーダで目標到達を監視します。停止タイミング補正は進捗差を使う独自制御です。2ポートの角度／回転数ではネイティブ同期も選択できます。
- 停止方法はポートごとにブレーキ・惰性・保持を設定でき、明示的な停止指定が優先されます。設定は動作終了時に参照します。
- 保持を含む作品には、スタート1個でも監督タスクを生成します。監督タスクが20ms周期の位置制御を行い、指令は±20％に制限します。プログラム終了時は保持を解除して停止します。
- 独立の有限動作中の速度変更は目標角度・終了時間を保持して追従します。待機中・停止中のモーターは速度変更だけでは起動しません。速度0は現在の動作を中止します。
- Lの未調整パワーから通常速度へ戻す場合、公開APIで元のL種別へ再構成します。MはL向けの未調整種別へ黙って変更しません。
- 実測速度は公開API ev3_motor_get_power が参照するドライバーのSpeed値を使います。
- PCの模擬モーターで正逆、台形／S字、負荷差、途中の速度変更、保持への外乱、型の切り替えを確認しています。実機の精度・負荷応答は未検証です。

アプリの「EV3-RT対応表 → EV3RTの制約・相違点（全グループ）」に、公開APIで未対応の機能、組合せの制約、標準FWとの違いを分けて登録しています。単に公開APIの機能がないことと、独自制御でも実現不可能であることは区別しています。


## 生徒向けの日本語コメント（v0.32.0）

app.cの冒頭に読む順番を示し、各ブロックの直前に処理内容・数値の単位を記載します。共有変数の元の名前、マイブロックの名前と引数、タスクの役割もコメントで対応付けます。プログラムの動作と中間データは変えません。

同梱のCODE_GUIDE.txtには、floatの数値表記、途中の計算値、ポートの組合せ、単位、returnと全体終了の違い、app.cfgの読み方を説明しています。コメントに利用者が付けた名前を入れる際は、Cのコメント終端や改行を無害化します。Cの識別子は自動生成のASCII名を維持します。

## v0.33.0：データ・センサー・表示と環境構築マニュアル

文字列は値構造体で受け渡し、UTF-8の120バイト・最大16変数を守ります。リストは1000項目×16、PIDは16制御器。各共有操作はセマフォで保護し、失敗時にはロックを開放して全体を停止します。入力式の評価はロック外で行い、呼出し中の待機によるデッドロックを避けます。

CSVはSD直下の /EBL_プログラム名_ログ名.csv。5000行まで、共有のログ状態を使い、毎行閉じます。標準PANサーバーにCSVダウンロードAPIはないため、取得はSDカード経由です。文字列の数式保護と引用符エスケープを維持します。

数値表示は自動生成5×7ドット字形の通常／2倍表示で、標準EV3と字体が異なります。点滅は監督タスクが約20ms周期で確認し、250msごとに切り替えます。滑らかな明滅は代用品に置換せず、出力時に拒否します。

HRP3公開APIはジャイロ角度／速度を別モードで読みます。EBLのVM向け複合モードとは異なり、同一ポートを異なるタスクで併用する構成をEV3RT生成時だけ拒否します。IRも同一ポートの異なるモードのタスク間混在を拒否します。

詳しいWindows新規環境構築とEBLとの差分は、dist/manual/のv0.34.2 HTML／PDFおよびev3rt-workbench.mdを参照してください。既存の標準EBLマニュアルはそのまま別資料として使います。

## v0.34.2：Cの独立ファイル化とブロック関数名・引数名の共通化

app.cにはスタート・イベント・main_taskを残し、マイブロックの関数本体をebl_myblocks.cへ、関数宣言をebl_myblocks.hへ分けます。補助処理と共有状態の実体はebl_rt_runtime.c、型・関数・extern変数の宣言はebl_rt_runtime.hへ置きます。

マイブロックの引数は、`speed`・`distance`などCで安全に使える英数字の名前をそのまま関数の引数に使います。宣言・定義・引数の参照で同じ名前になります。日本語、Cの予約語、補助処理・SDK API・標準関数・マクロ等と衝突する名前、重複や長すぎる名前は`lab_arg_0`などへ変換し、元の引数名と対応をコメントへ記録します。作品の保存データや通常の.rbf生成処理は変更しません。

3つの.cを別々にコンパイル・リンクします。Makefile.incのAPPL_COBJSとapp.cfgのATT_MODに追加オブジェクトを登録します。.cを#includeする方式ではありません。共有変数・タスクごとの終了先・セマフォは1つの実体を各ファイルから利用します。

分離はタスク・モーターの変換後、利用者のコメントを復元する前に行います。独自のCコードを分割する汎用ツールではありません。機能版12（myblock-function-names）の補助アプリが必要です。全ての.c/.hを同じ出力一式からそろえてください。

マイブロック名も `forward`・`turn_left` など安全な英数字なら、そのままCの関数名に使います。宣言・定義・通常呼び出し・戻り値付き呼び出し・イベントからの呼び出しを同じ名前で出力します。日本語や予約語、補助処理・API等と衝突する名前は `lab_proc_0` などへ変換します。引数が関数名と重なる場合は、呼び出しを隠さないよう引数を `lab_arg_0` などへ変換します。変換は出力Cに限り、元の作品名は変更しません。


## 現行のモーター速度とPID

最終速度を左右それぞれ−100〜100へ制限し、同一ペアの連続ステアリングでは更新ごとの不要なブレーキを省きます。PID出力・共有変数・式は変えません。PIDはループで1回計算して左右で共用します。Webは補助アプリ13、Windowsは0.3.5で再コンパイル・再転送してください。
