# EV3 Block Lab v0.23.0 共通モーター設定

2026年11月1日更新。
### 最初に使うブロック

「動きに使うモーターを 左 B 右 C にする」をスタートの直後につなぎます。左右はA〜Dから別々に選び、同じポートはエラーです。B・CとC・Bは別の設定です。左右はロボットが前進するときの向きを基準にし、実際の配線を確認します。初期表示はB・Cですが、プログラムに暗黙の既定設定はありません。

このブロックだけではモーターを回しません。編集エリアに離して置くだけでも設定は有効になりません。実行された時点から、その後の動き・マイブロック・並行処理・イベントで共有します。タイヤ直径、トレッド、速度や距離の範囲、ブロックの色は従来どおりです。距離・スピン・ピボットはLモーター直結、ステアリング・左右別速度は同じ種類のL同士またはM同士を使います。

| 動きの並び順 | ブロックの入力 |
| --- | --- |
| 左右モーター設定 → タイヤ直径 → トレッド | 配線は設定だけで選ぶ。寸法は従来の単位。 |
| ステアリング連続 → 角度 → 時間 | 曲がり方・速さ・必要な角度または秒数。 |
| 左右別速度の角度 → 時間 → 連続 | 左右の速さと必要な角度または秒数。 |
| 右／左スピン → 右／左ピボット | 速さとロボットの旋回角度。 |
| 前進 → 後退 | 速さと距離cm。 |

### 基本例とマイブロック

基本例：スタート → 動きに使うモーターを左B・右Cにする → タイヤの直径を56mmにする → 速さ20％で20cm前に進む。

サンプル「共通設定で前進」（MovementBasic.ev3lab）がこの構成です。「共通設定とマイブロック」（MovementMyBlock.ev3lab）では呼び出し側で左右と直径を設定し、定義「前進」の中にはポート欄のない前進ブロックを置きます。距離の引数を変えて再利用できます。寸法と配線の設定を「定義」などのマイブロックにまとめてから呼び出しても使えます。

### 途中で組を変える

サンプル「途中で左右モーター変更」（MovementSwitch.ev3lab）：左B・右C → 直径56mm → 20％で20cm前進 → 1秒待つ → 左A・右Dへ変更 → 20％で20cm後退。4個のモーターを使う例なので、試験する実機の配線に必ず合わせて変更します。

変更ブロックを実行すると、以前の左右モーターにブレーキ停止命令を送り、その後で新しい左右設定に切り替えます。停止までの機械的な時間を保証するものではありません。同じ左右設定を繰り返しても、不要な停止や再登録は行いません。B・CからC・Bへの変更も左右の意味が変わるため旧組を停止します。マイブロックから戻っても設定は自動で元に戻りません。

新しくプログラムを実行するたびに未設定へ戻ります。本体の電源を入れ直した後も同じです。保存された実行プログラムが先頭から設定を実行するため、以前の実行の配線状態に依存しません。

### 設定が不足している場合

「動きに使うモーターを設定してください」と生成・転送前に表示します。未接続の設定や、呼び出していない定義の設定は数えません。単一スタートでは、動きより後の設定、片側の条件分岐だけで行う設定、0回かもしれない繰り返しだけの設定、早期復帰して設定を通らないマイブロックなども検出します。両方の分岐で設定する構成や、設定済みの呼び出し元から動きの定義を使う構成は扱えます。

並行処理・イベントの順序は静的には保証できません。他の処理に設定があるだけでは、先に設定済みとは扱いません。EV3本体でも各動きの開始前に必ず共有設定を確認し、未設定なら全モーター停止・×とエラー番号23の画面表示・エラー音・プログラム終了を行います。番号23は「動きの左右モーターが未設定」の意味です。設定が済んでからメッセージを送って動作側を始めるなど、順序を明確にしてください。

同じモーターに複数の処理から同時に命令したり、動作中に別処理から左右設定を変更したりしないでください。配線設定は共有ですが、走行完了まで他の計測処理を止める仕組みではありません。センサの入力1〜4とモーターの出力A〜Dは別の物理端子です。同一の端子を異なる機器・モードとして利用する従来の検査は維持されます。実際の配線違いは未設定とは別の問題として確認します。

### 旧作品を読み込む場合

以前の動きブロックのポート欄は新しい画面に表示しません。旧作品からB+Cを黙って選ぶことはありません。「動きに使うモーター」を追加し、左右と実機配線を確認してから生成・転送してください。旧データにポート欄が残っていても、共通設定を上書きする値には使いません。編集データを保存し直すと新しい形になります。

### 所有者が担当する実機テスト

| 確認項目 | 確認方法 |
| --- | --- |
| 配線と基本走行 | 左右の実配線に合わせ、低速で前進・後退。B+C以外と左右逆の設定も試す。 |
| 旋回 | 直径・トレッドを実測して、右／左スピン・右／左ピボットを確認。 |
| 曲線と左右別速度 | ステアリングと左右別速度それぞれの連続・角度・時間を確認。 |
| 設定の反復と変更 | 同じ設定では連続回転を中断しないこと、別の組への切替時には旧組が止まり、その後は新組で動くこと。 |
| 再利用と並行処理 | 呼び出し側で設定したマイブロック、設定後にメッセージで動作を始める例。 |
| 単独モーター | 共通設定に含まれないアーム等を、従来のポート欄で動作・停止できること。 |
| 未設定エラー | 実行順が定まらない並行例で、未設定なら番号23とエラー音で停止すること。 |
| 単体実行 | 切断後・本体電源再投入後も先頭で設定を実行して動くこと。 |

自動テストとブラウザ確認の成功は、実機確認済みを意味しません。OS・ブラウザ・本体FW・配線・モーター種別と結果を記録してください。生成する実行プログラムの上限64KBは従来どおりです。多くの異なる配線設定と長い補正走行を組み合わせて超える場合は、プログラムを分けてください。
