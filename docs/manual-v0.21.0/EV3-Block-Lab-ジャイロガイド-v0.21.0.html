EV3 Block Lab v0.21.0 ジャイロセンサと実機テスト

2026年10月31日更新。統合マニュアル v0.21.0 の第35章にも収録した内容です。今回のジャイロ機能は自動テスト・ブラウザ確認の後、実機での検証を進める段階です。

追加したブロック

「センサー」グループの「EV3 ジャイロセンサ」にあります。入力ポート1〜4を選びます。

ブロック役割
ジャイロセンサ 1 の角度（度）回転した角度を数値で返します。逆方向は負。360度で0には戻りません。
ジャイロセンサ 1 の回転速度（度／秒）1秒あたりの回転角度を数値で返します。逆方向は負になります。
ジャイロセンサ 1 の角度／回転速度が ＜ 90数値と比較して真偽を返します。＜・＝・＞・≦・≧・≠を選べます。
ジャイロセンサ 1 の角度を0にする現在の向きを、このプログラム内の0度として記録します。

角度・回転速度は、変数への代入、演算、条件分岐、待機、繰り返し、センサの変化によるイベント、マイブロックの引数、CSV記録、本体画面の数値表示に使えます。PCを切り離した後もEV3本体で読み取ります。

角度と回転速度は、EV3の複合モード GYRO-G&A の2つの値から選びます。同じセンサの角度と回転速度を別の処理で読んでも、モードを切り替えません。センサの種類・モードが違う、または値が不正な場合は、全モーターを停止してエラー音を出し、終了します。接続や認識状態も実機で確認してください。

0度の基準とセンサの再校正

「角度を0にする」は、測定した角度を基準点として覚える操作です。ポートごとに独立し、同じポートを使うすべての並行処理・マイブロックで基準を共有します。プログラムを起動し直すと基準点の記録は初期化されます。開始位置から測りたい場合は、開始時にリセットブロックを置きます。

この操作はセンサ本体の再校正ではありません。「接続・転送」のポート表示はセンサの生値を読むため、リセット後のプログラム内の角度とは異なる場合があります。ポート表示には「角度（センサ生値）」と表示します。プログラム内の角度の確認には、角度ブロックを本体画面に表示するか、CSVへ記録してください。

接続・リセット時はセンサを静止させてください。静止中も角度が変化する場合は、ロボットを止めてセンサのケーブルを挿し直し、値が安定することを確認します。ゼロにする操作だけでは、回転速度のずれを補正しません。正負の向きはセンサの取付方向により変わるため、最初に手で回して確認します。数値はセンサの範囲に依存し、長時間の累積測定ではドリフトや角度カウンタの範囲にも注意してください。

並行する処理がすでに角度を読んでいる途中でリセットすると、イベントが発生する場合があります。初期化が終わってから測定を始めたい場合は、1つのスタートでリセットを行い、その後にメッセージを送って測定側の処理を開始してください。

最初の実機テスト モーターを動かさずに確認

1. ジャイロセンサをEV3の入力ポート1へ接続し、水平な場所で静止させます。

2. サンプルメニューの「ジャイロの角度・回転速度」を選びます。ファイル版は GyroTest.ev3lab です。

3. 「EV3に転送・照合」で転送し、本体で EV3Lab → GyroTest を実行します。「転送して実行」でも確認できます。

4. 実行開始後は1秒間静止させます。角度の基準を0にした後、開始音が鳴ります。

5. 音の後、約10秒間、センサをゆっくり回します。本体画面の上が角度、下が回転速度です。ゆっくり90度程度回す・元に戻す・逆方向へ回す・静止する操作を試します。画面更新や記録のため、測定間隔・所要時間は約0.2秒／約10秒より長くなります。

6. プログラム終了後、再接続します。「接続・転送」の「CSVログを取り出す」でログ名を Gyro にして「EV3からCSVを保存」を押します。保存先プロジェクトは転送時と同じ名前にします。

7. CSVには time_s,item,value の列で angle_deg と rate_deg_s を各50行、合計100行記録します。角度・回転速度は順番に読むため、同一瞬間の測定値ではありません。

同じ Gyro ログ名で再実行すると、前回のCSVを上書きします。比較用のファイルはPCやChromebookへ保存してください。

条件でモーターを止める確認

基本測定が確認できた後、低速で試します。「角度を0にする → タイマーをリセット → モーターを回し続ける → （角度の絶対値が90以上 または タイマーが5秒以上）まで待つ → モーターを停止」の順に組みます。回転方向に左右されないよう絶対値を使い、条件が成立しない場合にも停止する待機時間を設けます。モーターの惰性・負荷・測定周期により、停止後の角度が指定値を超えることがあります。90度での厳密な停止を保証する機能ではありません。
