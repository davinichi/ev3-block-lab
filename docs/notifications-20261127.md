# 通知・エラーの表示場所

プログラムのエラーは編集エリア上部に表示します。修正すると消えます。該当ブロックへ移動するボタンは今回追加しません。接続・転送のエラーは操作ボタン付近、保存結果は「保存」の近くに表示します。ファイルのダウンロード開始通知は約5秒で消え、エラーは残ります。詳しい通信ログは画面下部に残します。

Program errors appear above the block editor and clear after repair. No jump-to-block button is included. Connection and transfer errors appear beside the relevant controls. File notifications appear beside Save; download-start notices clear after about five seconds, while errors remain visible. Detailed communication logs stay at the bottom.
