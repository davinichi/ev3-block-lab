# EV3 Block Lab v0.22.0 バッテリーとPID制御

2026年10月31日更新。バッテリー取得とPID計算は、転送後はEV3本体で動作し、ブラウザを切り離しても使えます。今回の追加機能の実機動作は検証待ちです。

## バッテリーの2つのブロック

「センサー」グループの「EV3 バッテリー」にあります。ポートの選択は不要です。

| ブロック | 返す数値 |
| --- | --- |
| EV3本体のバッテリー電圧（V） | バッテリー全体の電圧。単位はV、小数あり。残量の％ではありません。 |
| EV3本体のバッテリー電流（A） | 本体・接続機器を含むバッテリー全体の消費電流。単位はA、小数あり。各モーターの電流ではありません。 |

電流をmAで扱う場合は1000を掛けます。電圧・電流は、変数・比較・演算・CSV記録・本体画面の数値表示に使えます。例えば「電圧×電流」で消費電力の目安をW単位で求められますが、2つの値は順番に取得するため、厳密な同時測定ではありません。本体の測定値であり、校正された計測器としての精度を保証しません。

## PIDの入力と出力

「制御」グループの「PID制御」にあります。PIDブロックは数値を返す丸いブロックです。単独ではモーターを動かしません。

| 入力 | 意味 |
| --- | --- |
| PID名 | 初期値はPID1。同じ名前は同じ制御器、違う名前は別の制御器です。1〜40文字、全体で16種類まで。 |
| 目標値 | 到達させたい値。数値・変数・演算・引数を使えます。 |
| 測定値 | センサなどで得た現在の値。目標値と同じ単位にします。 |
| Pゲイン | 現在の偏差に対する比例ゲイン。初期値1。 |
| Iゲイン | 偏差の積分に対する積分ゲイン。初期値0。 |
| Dゲイン | 偏差の変化速度に対する微分ゲイン。初期値0。 |
| 出力 | PID計算の結果を数値で返します。変数・モーターの速さ・表示・記録などへつなぎます。 |

符号を含めた小数のゲインを使えます。モーターの向きや目標値の単位により、適切なゲインと出力の単位は変わります。

## 計算式と時間

偏差 e ＝ 目標値 − 測定値

偏差の積分 I ＝ 前回の積分 ＋ 今回の偏差 × 経過秒数

偏差の変化速度 D ＝（今回の偏差 − 前回の偏差）÷ 経過秒数

出力 u ＝ Pゲイン × e ＋ Iゲイン × I ＋ Dゲイン × D

経過秒数はEV3本体のミリ秒時計で自動計測します。表示用タイマーのリセットでは変わりません。初回は積分と微分を0とし、P項だけを返します。同じミリ秒内の再評価は、ゼロ除算や積分の二重加算を避けるため、前回出力を返します。入力やゲインを変えても、次のミリ秒までは同じ結果になる場合があります。前回計算から60秒を超えて空いた場合は、古い積分を消してP項から再開します。

「ずっと」の中で計算し、例えば0.02秒待つ構成から試します。これは厳密な20ms周期の保証ではなく、センサ取得やCSV保存などの処理時間も加わります。実際の経過時間を使って積分・微分を計算します。D項は測定の揺れや目標値の急変で大きくなるため、最初はI・Dを0にしてPだけで確認してください。

## リセットと状態の共有

「PID PID1 をリセットする」は、積分・前回の偏差・前回時刻・出力を初期化します。次の計算はP項だけです。モーターを動かしたり止めたりする命令ではありません。プログラムの実行開始時にも、すべてのPIDを初期化します。

同じPID名は、別のブロック・マイブロック・並行処理でも状態を共有します。名前が同じ処理は内部で順番に計算しますが、複数の処理が別々の目標値を渡すと制御に干渉します。1つの制御器の更新担当は1つに決め、出力を変数に保存してほかの処理で使ってください。左右など別の制御には、異なるPID名を付けます。マイブロックを読み込んだ際も、同じ名前のPIDは共有するので確認してください。

## 出力をモーターへ渡す

このPIDには出力上限・積分上限や自動調整機能はありません。モーターの速さに渡す場合は「値を−100から100の範囲に収める」ブロックを使います。最初は−20〜20など小さい範囲に収めて実機を確認します。

例：PIDをリセット → ずっと［出力にPIDの計算結果をセット → 出力を−20〜20に収めてモーターを回し続ける → 0.02秒待つ］。

連続回転の速さは負なら逆転、0なら停止です。角度・時間を指定する有限動作では速さ0は使えません。センサや制御の用途に合った停止条件を組み合わせます。

出力を範囲内に収めても、PID内部の積分値は増え続ける場合があります（積分ワインドアップ）。この版に自動的な積分抑制はありません。目標変更や試行の前にリセットし、Iゲインは小さい値から確認してください。実行中に不正な数値や計算範囲超過を検出した場合は、全モーター停止・エラー音・プログラム終了の処理へ進みます。

## モーターを動かさない実機テスト

| サンプル | 確認方法 | CSV名 |
| --- | --- | --- |
| バッテリー電圧・電流 | BatteryTestを転送・実行。本体画面の上がV、下がA。約0.5秒待ちながら各20回を記録します。 | Battery |
| PID計算（モーターなし） | PIDTestを転送・実行。目標10、測定4、P=1、I=0.5、D=0.1で10回計算。初回出力は6、その後は積分の分だけ増えます。 | PID |

測定間隔には表示・記録の処理時間も加わります。PIDTestの測定値は固定値で、実際の機械をフィードバック制御するサンプルではありません。I=0、D=0にして出力が6のままになること、リセット後に初回の値へ戻ることを比較できます。

終了後に再接続し、「接続・転送」の「CSVログを取り出す」で、上表のログ名を指定して保存します。同じログ名で再実行すると前回のCSVを上書きします。成功・不具合のどちらも、アプリの版、端末とブラウザ、EV3のファームウェア、Bluetooth／USB、プログラム・CSV・通信ログを記録してください。
