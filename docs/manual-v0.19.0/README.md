## 追加したブロック

|場所|機能|意味|
|---|---|---|
|モーター|L/M・1個/2個の回転数指定|1回転＝360度。0.5回転などを指定。角度制御と同じ同期・加減速を利用|
|モーター|動作後の停止方法|ポート別にブレーキ・惰性・保持を設定。後ろの有限動作と既定の停止に適用|
|モーター|停止方法を選ぶ停止|選択したポートを直接その方法で停止。旧データは既定の動作を維持|
|モーター|パワーで回し続ける|出力率を固定。速度の自動調整はしない|
|モーター|速さを変更|動作中の速さを変更。停止中のモーターは始動しない|
|動き|左右別速度で角度指定|速い側の回転角度を指定。遅い側は速度比に応じた回転量|
|動き|左右別速度で時間指定|左右別速度で指定秒数を走行。負の値で逆回転|
|センサー|実際の速さ|EV3本体が測定した現在の速度。設定値ではない。−100〜100％|

左右30％・15％で360度なら、約360度・180度回ります。両方360度を指定するブロックとは異なります。L同士・M同士を使い、標準FWの同期機能で動かします。比率は約1％刻み。左右別速度の有限走行には加減速設定を適用しません。

## 停止方法

- 惰性：力を抜く。慣性で指定角度を越える場合がある。
- 保持：標準FWの能動的な位置保持。プログラム実行中だけ有効。
- ブレーキ：100ms制動してから解放する試作方式。負荷による停止時間の違いは残る。
- 設定どおり：ポートの設定を利用。設定のない旧作品は従来の標準FWの制動を維持。

標準FWのBRAKE=1には位置保持の働きもあります。新しい短時間ブレーキと区別しています。
プログラム全体の終了・本体の戻るボタン・電源断後は保持を保証しません。
同期走行の2ポートは同じ停止方法にします。異なる設定は実行時にエラー音で全体を停止し、同期走行を始めません。

## 範囲と注意

速度・パワーは−100〜100％。ハードウェア値は整数に切り捨てます。角度は1〜36000度、回転数は換算後にこの範囲。左右別速度の時間は0.001〜60秒です。
パワー指定の値と速度指定の値は同じ物理量ではありません。0パワーは保持ではありません。
同じモーターを並行処理から操作すると命令が干渉します。特に同期・加減速の途中へ速度・パワー命令を混ぜる場合は、制御を担当する処理を1つにまとめます。

自動試験では全ポート順と正負の速度比、符号付き実測速度、停止方法、回転数の換算、保存・読み込みとマイブロック再利用、RBFの命令境界を確認します。模擬実行は慣性・摩擦・保持力を再現しません。追加機能のEV3実機試験は継続が必要です。
