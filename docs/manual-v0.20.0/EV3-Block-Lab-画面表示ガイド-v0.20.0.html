EV3本体画面の表示（v0.20.0）

「画面」グループからブロックを選びます。本体の画面は白黒178×128ドット。左上が横0・縦0で、右へ行くと横、下へ行くと縦の値が増えます。

4つの表示ブロック

ブロック使い方
本体の画面を消す画面全体を白くします。新しい表示の前に置きます。
本体に文字を表示文字欄に日本語や英数字を直接入力します。文字の大きさは小12・中16・大24ドット。長い文字は178ドット幅で折り返します。位置を含めて画面に入らないと転送前に知らせます。
本体に画像を表示えがお・かなしい顔・びっくりした顔・ハート・チェック・ばつ・上下左右の矢印から選びます。大きさは48または96ドットの正方形です。
本体に数値を表示変数・センサ・演算・タイマーなどを差し込めます。小数点以下0〜3桁。小は80×9、大は160×19ドットの表示欄です。符号・小数点を含め先頭10文字までなので、大きな数は桁を確認してください。

表示を確認する

上部の「サンプル」→「本体画面の表示」を開くと、文字「こんにちは EV3」・えがお・タイマーの値を表示し、5秒待ちます。転送して実行し、本体画面をご確認ください。このサンプルのタイマーは表示命令を実行した時点の値で、待っている間は更新しません。

表示ブロックはすぐに次の命令へ進みます。直後にプログラムを終えると、表示が見えないことがあります。後ろに「5秒待つ」を置くか、数値を繰り返し更新します。例：ずっと → 数値（超音波センサ2の距離）を表示 → 0.1秒待つ。ロボットの走行とは別のスタートにつなげることもできます。

保存と注意点

文字・画像の領域は白く消してから描き直します。それ以外の画面は残るため、位置や文字数を変えた場合は「画面を消す」を使ってください。画面からはみ出す場合は位置・大きさを調整します。

日本語は転送時にブラウザのフォントで白黒画像に変換し、画像の描画命令を実行ファイルに埋め込みます。追加の画像ファイルやファームウェアの変更は不要で、PCから切り離しても表示できます。日本語の字形は作成した端末のフォントによって異なります。文字を変数から動的に差し替える機能や、画像ファイルの読み込みは今回の対象ではありません。

作品ファイル・マイブロックの書き出しと読み込みにも対応します。複数の並行処理からの描画は、1ブロック単位で順番に行います。同じ場所への表示内容は、後から実行したブロックのものになります。複雑な画像や多数の文字で実行ファイルの64KB上限を超える場合は、文字数・大きさ・表示回数を減らしてください。

生成命令・保存・模擬実行を確認しています。本体画面での表示品質・更新速度は実機での確認待ちです。
