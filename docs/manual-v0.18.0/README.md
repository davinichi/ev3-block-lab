## 使い方

スタートを複数置くと、それぞれの命令をEV3本体で並行して実行します。
角度・時間指定の走行中も、別のスタートでセンサ値の取得やCSV記録ができます。
スタートだけのプログラムは、全スタートの完了後に全モーターを停止します。

「イベント」に以下の5ブロックがあります。

|ブロック|動作|
|---|---|
|条件が成り立ったとき|偽→真になったときに実行。開始時に真でも1回実行。真のままでは繰り返さない|
|値が変わったとき|最初の数値を基準に、その後の変化で実行|
|名前を受け取ったとき|同じ名前のメッセージで実行|
|名前を送る|送信後すぐ次へ進む|
|名前を送って待つ|対応する受信処理が全部完了するまで待つ|

イベントがあるプログラムは、スタートが終わっても監視を続けます。
終了には「プログラムを終了する」または本体の戻るボタンを使います。
「すべてのモーターを停止」はプログラム全体の終了ではありません。

## 仕様・制限

- スタート・イベント・受信は合計16個、メッセージは32種類、生成RBFは64KB以内。
- 監視は読み取り・処理後に約20ms待つ方式。正確な周期を保証しない。
- 同じイベントを重ねて実行しない。実行中の短いセンサ変化は取り逃す場合がある。
- 受信処理中の追加メッセージはまとめ、完了後に最新分をもう1回実行する。件数保証のキューではない。
- 自分自身・循環する「送って待つ」は転送前にエラー。受信側が無限ループの場合も送信側は待ち続ける。
- 変数・タイマー・寸法・加減速・リスト・文字列・CSV記録状態は共有。引数と作業領域は各処理で独立。
- 同じモーターへの別処理の命令は競合する。走行を担当する処理を決め、メッセージで連携する。
- 同じ入力ポートの異なるセンサモードを並行処理から使う構成はエラー。
- CSV・リスト・文字列・変数の変更は内部で排他。同時に別々のCSV記録を開始する用途は未対応。
- 記録開始→全員の記録→記録終了の順を、メッセージの完了待ちなどでそろえる。
- 距離・旋回の各処理内で、寸法を設定するマイブロックを先に呼ぶ。他のスタートの設定順には依存しない。

## 検証範囲

生成したRBFを命令ごとに切り替える試験実行器で、走行待機中の計測、イベントの成立・再成立、複数受信の完了待ち、引数の独立性、共有変数・リスト・CSVの排他を確認しました。別の構造検査でオブジェクト境界とジャンプ先を検査しています。保存・読み込み・マイブロック再利用とブラウザ表示も確認します。

これらは実機試験の代わりではありません。新機能の標準EV3実機、Bluetooth/USB、Chromebookでの確認は継続が必要です。
