# SBL・EBL 共通ブロックの相互読み込み

2026年11月28日 ／ SBL v1.1.0・EBL Web v0.26.0

## 開く手順

現在の作品を残したい場合は、先に「保存」を押します。「開く」から相手の作品（.ev3lab／.spikelab）を選びます。変換内容の確認画面で共通ブロック数と要確認の一覧を確認し、「変換して開く」を押します。「キャンセル」では編集中の作品を置き換えません。

## 共通として変換するもの

スタート、条件分岐、回数・条件による繰り返し、待つ、変数、四則演算・比較・論理演算・数値関数、名前付き文字列・数値リスト、音、タイマー、PID計算、CSV記録、マイブロックの定義・呼出し・引数・最大8個の名前付き戻り値などを変換します。未対応の演算や古いブロックは推測せず要確認として残します。

## 機種固有のブロックを残す

モーター、動き、機器に依存するセンサー、ジャイロ、電池、本体表示・ライトなどの自動変換は行いません。赤い「要確認」ブロックに元のブロックと内部の内容を保持します。下につながる共通ブロックは変換します。要確認ブロックの内部はそのまま保持され、通常の編集画面には展開しません。

## 実行する前に

要確認ブロックが1個でも残る間は、Python／実行ファイルの生成と転送を止めます。無効化したりスタートから外したりしても解除しません。使う機種の適切なブロックに置き換え、ポート・回転方向・単位・表示方法を確認してください。意図して削除する場合も元の内容は変換前の作品から取り出せます。

## 元の作品と別名保存

読み込んだ元ファイルは変更しません。SBLへ変換した名前には _SBL、EBLへは _EBL を付けます。EBLの名前は半角英数字・ハイフン・アンダースコアの31文字以内に整えます。SBLにはEV3固有のプロジェクト名欄を追加しません。

## 変換前の作品を取り出す

確認画面の「元の作品を保存」、または「教員・指導者用 → 変換前の作品を保存」で、変換する前の作品をダウンロードできます。変換後の作品ファイルには元の作品も含めて保存します。ファイルを開き直しても元の作品を取り出せます。保存先やファイル名を手動で元ファイルと同じに変更しないでください。

## 互換性と上限

これは編集用作品ファイルの変換です。LEGO純正の .ev3 や .llsp、実行用 .rbf は対象外です。共通ブロックでもPIDの実際の周期、音の鳴り方、記録方法・保存上限などは機種ごとに異なります。SBLは画面上500ブロック、EBLは1000ブロックの上限など各アプリの制約が適用されます。入力は2MiBまで。元作品を含む保存で大きくなった場合は、元ファイルを別途保管して作品を分けてください。

## 検証範囲

変換・元データの保持・保存再読込・変数と引数・複数戻り値・キャンセル・元作品の取り出し・生成阻止を自動試験で確認しています。PythonとEV3実行ファイルの生成も確認します。機種間で動作や精度が同じになることを保証するものではなく、実機動作は未確認です。EBL-RTとWindows専用アプリは今回の変更対象ではありません。
