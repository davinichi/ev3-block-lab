## 開発の目的と初期段階

SBLは、授業でSPIKE Primeをブロックで操作し、本体に保存してPCを切り離して使うために開発しました。開発の動機は、基本のプログラミングから計測・データ処理、将来的なSPIKE-RT連携へ学びを広げることです。Windows PCの老朽化を理由としたものではありません。

v0.2〜v0.5では、Bluetooth転送・実行、モーター・動き・センサー・音・表示、並行処理、マイブロックなどを整備しました。Pythonの字下げ、モーター組の重複登録、センサー通知のエラー処理を修正し、v0.5.0で動きの左右モーターを共通設定する方式に移行しました。v0.6〜v0.7で戻り値と授業用マニュアルを整備しています。

### v0.11系の同一版内で行った追加修正（11月26〜27日）

- 接続・転送ボタンは緑系、未接続は灰色、接続中と接続欄の接続ボタンは赤へ調整。
- USBのパケット間隔と初期応答の再試行・診断を整備。USBからBluetoothへ切り替える場合の読取要求の再試行を追加。本体の自動リセットやプログラムの自動再実行はしない。
- 「まで繰り返す」「の間繰り返す」を2つの固定ブロックにし、切替プルダウンを削除。既存作品のUNTIL／WHILE設定は維持。
- 分かりにくいブロック数・処理数、初期の「実機テスト待ち」、フッターの試作ツール表記を整理。出典・ライセンスをUTF-8の閲覧ページへ変更。
- プログラムのエラーは編集エリア上部、接続・転送エラーは操作の近く、保存通知は保存ボタン付近へ配置。詳細な通信ログは下部へ維持。
- 上部を「ヒント・お知らせ」にし、通常は「ブロックをつないで、動きを作ろう。」、エラー時は修正内容を表示。縦ラインを外した。「該当ブロックへ」ボタンは保留。
